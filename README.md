# NYC Airbnb Market Analysis

## Project Overview

This project explores the New York City Airbnb market using listing-level data to examine pricing patterns, room-type distribution, listing concentration across boroughs, and guest review ratings.

The goal was to identify market trends and translate raw listing data into an interactive Power BI dashboard that makes the findings easy to explore.

## Dashboard Preview

![NYC Airbnb Power BI Dashboard](images/airbnb-dashboard.png)

## Tools & Technologies

* **Power BI** — Interactive dashboard development and data visualization
* **Power Query** — Data preparation and transformation
* **Microsoft Excel** — Initial exploratory analysis and validation
* **SQL** — Planned extension for querying and further analysis

## Business Questions

1. How do average listing prices vary across NYC boroughs?
2. How does pricing differ between entire homes/apartments, private rooms, and shared rooms?
3. Which boroughs have the highest concentration of Airbnb listings?
4. What proportion of listings belongs to each room type?
5. How do guest review ratings compare across room types, and do ratings appear to vary with listing prices?

## Key Findings

* **Manhattan had the highest average listing price** among the five boroughs, at approximately $198.47.
* **The Bronx had the lowest average listing price**, at approximately $94.66.
* **Entire homes and apartments were substantially more expensive**, averaging approximately $220.80, compared with $91.92 for private rooms and $80.51 for shared rooms.
* **Average guest ratings varied less than average prices** across room types, suggesting that the large price differences were not matched by equally large differences in average ratings.

## Dashboard Features

* KPI cards summarizing listing volume, average price, average rating, and room-type variety.
* Interactive drill-downs to explore listing counts and average prices by borough and room type.
* A room-type distribution chart showing the share of listings by accommodation type.
* A price-distribution histogram to examine the concentration of listings across price ranges.
* Interactive filtering to explore different segments of the market.

## Data & Limitations

The analysis uses an NYC Airbnb listings dataset containing approximately 30,500 records and fields relating to host information, neighbourhood, property type, room type, price, and review ratings.

* Missing values and unusual categories may affect individual metrics and visualizations.
* Average prices can be influenced by unusually expensive listings.
* The price-distribution chart focuses on listings priced from $0 to $500 to improve readability; listings outside this range are excluded from that visual.
* Observed relationships between price and ratings should not be interpreted as evidence of causation.
* Dataset source, collection date, and licensing details should be documented when verified.

## How to Access the Report

Download `NYC_Airbnb_Analysis.pbix` from this repository and open it using Power BI Desktop to explore the interactive dashboard and drill-down functionality.

## Future Improvements

* Extend the analysis using SQL queries.
* Investigate relationships between host tenure, listing prices, and review activity.
* Add further analysis of pricing distributions and neighbourhood-level trends.
* Document data cleaning decisions and analytical methods in greater detail.
