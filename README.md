# NYC Airbnb Market Analysis

## Overview

This project analyzes Airbnb listings in New York City to explore pricing differences across boroughs and room types, along with guest rating patterns. The project uses Power BI to create interactive visualizations and support data-driven insights.

## Tools

* Power BI
* Power Query
* Excel

## Business Questions

* Which NYC boroughs have the highest average listing prices?
* How do prices vary by room type across boroughs?
* Do guest ratings differ by room type?
* Is there a relationship between listing price and guest rating?

## Preliminary Findings

* **Manhattan** has the highest overall average listing price in the dataset, at approximately $198.47.
* **The Bronx** has the lowest overall average listing price, at approximately $94.66.
* Entire homes/apartments average approximately $220.80, compared with $91.92 for private rooms and $80.51 for shared rooms.
* Average guest ratings are relatively similar across room types, ranging from approximately 90.62 to 92.50.

## Data

## Limitations

* Average prices may be influenced by unusually expensive listings.
* Missing values may affect individual analyses.
* Findings describe this dataset and should not automatically be generalized to the entire NYC Airbnb market.
